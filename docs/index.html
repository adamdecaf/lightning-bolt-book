Lightning Book of BOLTs

The Lightning Network Specifications, arranged to be read.

The BOLTs are the contract between Lightning implementations. They are numbered as a catalog. This book leaves that text alone and puts it in the order a node actually uses it: connect, open a channel, route a payment, settle on-chain.

I didn't write the specs. Credit belongs to the original BOLT authors. I'm Adam Shannon; I compiled the reading order and the short chapter intros.

Get the book: ePUB or PDF.

Reading order:

  1. Overview — what Lightning is, then BOLT 00
  2. Connecting nodes — Transport (08), Messaging (01), Features (09)
  3. Opening and running channels — Peer protocol (02), Transactions (03)
  4. Routing payments — Onion routing (04), Gossip (07)
  5. Paying people — Invoices (11), Offers (12)
  6. When channels close — On-chain (05)
  7. Finding the network — DNS bootstrap (10)
  8. Newer work — Simple Taproot Channels
